## 1. Назначение

**Riool SpecManager («СпецМенеджер»)** — локальное настольное Windows-приложение для работы с техническими проектами, спецификациями оборудования и материалов, а также для подготовки заявок поставщикам.

Типовая задача: в техническом проекте десятки позиций оборудования, кабельной продукции и крепежа. Требуется собрать данные из проектных ведомостей, проверить наименования и количества, вести единый список позиций, а затем сформировать закупочную заявку без повторного ручного переноса каждой строки.

Программа демонстрирует прикладную автоматизацию такого процесса. Она не является ERP-системой или сервисом онлайн-закупок; все ключевые действия выполняются на компьютере пользователя.

## 2. Для кого

- Для инженеров и технических специалистов, работающих со спецификациями.
- Для монтажных и подрядных организаций, готовящих ведомости материалов.
- Для сотрудников, формирующих заявки на закупку оборудования и комплектующих.
- Для небольших команд, которым нужен локальный инструмент вместо ручного ведения разрозненных таблиц.

## 3. Основные возможности

### Проекты
- Создание и ведение отдельных проектов.
- Просмотр списка проектов и открытие ранее сохранённого проекта.
- Хранение относящихся к проекту спецификаций и истории заявок.

### Спецификации
- Ввод, проверка и редактирование позиций.
- Поля: исходный номер позиции, наименование, характеристики, марка, изготовитель, единица измерения, количество, примечание и, при импорте PDF, номер страницы.
- Группировка по разделам; сохранение порядка строк при импорте, повторном открытии и экспорте.
- Удобное представление категорий «оборудование → кабельная продукция → метизы».

### Импорт Excel (XLSX)
- Выбор исходного файла.
- Сопоставление колонок файла с полями приложения.
- Предварительный просмотр перед записью данных в проект.
- Ручная проверка и коррекция информации до завершения импорта.

### Импорт PDF
- Для **PDF с текстовым слоем** — поиск листов спецификаций и извлечение таблиц с учётом расположения строк, столбцов, страниц и разделов.
- Для **сканированных PDF** — локальное OCR-распознавание с использованием PDFium и Tesseract (русский язык).
- Строки с сомнительным распознаванием помечаются для проверки.
- Программа проверяет обязательные поля: наименование, единица измерения, положительное количество. Некорректные данные необходимо исправить перед импортом.
- В проверенном сценарии кабельный журнал исключается по заголовку, чтобы не смешивать его со спецификацией.

**Важно:** OCR не гарантирует точности, особенно на сложных, низкокачественных и нестандартных сканах. Результат необходимо сверять с оригинальным документом.

### Заявки поставщикам
- Выбор требуемых строк спецификации и формирование заявки.
- Сохранение заявок и их истории.
- Экспорт в стандартный XLSX или в XLSX-шаблон заказчика с сопоставлением полей.
- Неподтверждённые цены и суммы **не выдумываются**: соответствующие поля остаются пустыми, пока пользователь их не заполнит или не подтвердит.

## 4. Пример рабочего сценария

1. Установить и запустить программу.
2. Создать новый проект.
3. Импортировать спецификацию из XLSX или PDF либо заполнить позиции вручную.
4. Проверить предпросмотр, исправить сомнительные строки и обязательные поля.
5. Сохранить спецификацию в проекте.
6. Выбрать позиции для закупки и сформировать заявку.
7. Экспортировать заявку в XLSX.
8. Повторно открыть проект и при необходимости продолжить работу с сохранёнными данными.

## 5. Хранение данных и конфиденциальность

- Используется **SQLite**, данные хранятся локально на компьютере пользователя.
- Новая установка **не содержит заранее заполненной базы**, демонстрационных проектов или заявок.
- При первом запуске приложение автоматически создаёт пустую SQLite-базу и таблицы по адресу:
  `%LOCALAPPDATA%\Riool\SpecManager\specmanager.db`
- Пользовательские данные не размещаются в каталоге установки и не удаляются при штатном обновлении приложения.
- Штатное удаление приложения также сохраняет пользовательские данные.
- PDF и OCR обрабатываются локально, без отправки проектных документов на сервер разработчика.
- Если пользователь обновляется с предыдущей версии, его существующие записи сохраняются; программа **не удаляет** ранее созданные записи автоматически.

## 6. Установка и системные требования

**Платформа:** Windows x64; приложение разработано на C# / .NET 10 (WPF). Публичная сборка self-contained: обычному пользователю не требуется отдельно устанавливать .NET SDK.

1. Перейти на [страницу загрузки](https://tools.riool-hw.ru/specmanager.html).
2. Скачать **Riool_SpecManager_Setup_0.2.9.exe** (около 212 МБ).
3. Запустить установщик.
4. После установки открыть **Riool SpecManager** из меню «Пуск».

Программа устанавливается в `%LOCALAPPDATA%\Programs\Riool SpecManager`, без обязательных прав администратора. Установочный журнал: `%LOCALAPPDATA%\Riool\SpecManager\setup.log`.

**Примечание по установке:** установщик пока не имеет цифровой подписи издателя, поэтому Windows SmartScreen может показать стандартное предупреждение.

## 7. Техническая реализация

- **C# / .NET 10, WPF:** пользовательский интерфейс.
- **SQLite:** локальная база проектов, спецификаций и заявок.
- **ClosedXML:** работа с XLSX.
- **PDFium и Tesseract:** локальная обработка и OCR PDF.
- Разделение на графический клиент и независимую бизнес-логику `Riool.SpecManager.Core`, что позволяет проверять часть сценариев автоматическими тестами.
- Инсталлятор включает необходимые компоненты для распространения Windows-приложения.

Разработка и выпуск выполнялись с применением ИИ-инструментов (ChatGPT и Codex), при постановке задач, проверке результатов и приёмке человеком. Это **собственный демонстрационный продукт**, а не выдуманный оплаченный заказ.

## 10. Известные ограничения и дальнейшее развитие

**Ограничения текущей версии:**
- Работа с нестандартными PDF и сканами может потребовать ручного исправления результатов распознавания.
- У установщика отсутствует цифровая подпись.
- Программа работает локально; функции облачной синхронизации, коллективной работы и онлайн-обмена с поставщиками не заявляются.

**Возможные направления развития (не реализованные функции):** расширение шаблонов экспорта, дополнительные сценарии импорта, улучшение OCR, развитие отчётности и пользовательского интерфейса — по результатам обратной связи и будущих требований заказчиков.
